# 主站、地区 Edge 与发布实施记录

用户批准范围：主站统一管理、多地区实时转录 Edge、主站/Edge 蓝绿、一键安装、CLI 可视化、管理 UI、协议与运维文档、完整 CI 验证。生产目录 `/root/dreamtrans`；现有多 Compose 叠加、external 应用卷和数据库卷必须保留。禁止复制可写生产状态、回滚数据库快照或将主站密钥下发 Edge。

## 实施顺序及验证边界

1. 主站状态迁移和部署控制：SQLite RAG/配置迁 PostgreSQL；已有租约任务增加 standby/active/draining admission；真实请求/WS/任务计数。
2. 固定代理蓝绿控制器：不可变镜像、兼容性清单、恢复部署实际卷识别、16002 首次维护交接、锁和状态恢复、按计数排空、回切。
3. 主站 Edge 协议：独立节点身份、一次性注册、Ed25519 接入授权、事务预算预留、租约代次、幂等事件与账本结算。
4. Edge 运行时：直接供应商 WS、有界持久回传、预算/租约截止、音频序号和恢复、健康心跳与指标。
5. 浏览器调度/重连、管理控制台、安装器与独立 Tunnel 生命周期、备份。
6. 完整后端 CI + 前端 CI + 镜像/生命周期/故障集成验证。

本地 Docker 验证不能代替 Ubuntu 26.04 新 EC2 安装或真实多地区延迟测试；这些必须有真实环境证据。当前未操作生产机器或创建 Cloudflare 资源。

## 首次转换约束

旧 release 3763a83 不支持排空协议，也不能与新进程并写 SQLite。第一次转换需要明确维护窗口，停止旧写入后最终导入。后续转换不会更换数据库/应用数据卷；旧 SQLite 保留但不再被蓝绿应用打开。不能回切到 SQLite 旧镜像，否则会形成分叉。
