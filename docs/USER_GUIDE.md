# 用户使用指南（统一响应式 UI）

DreamTrans 现在只有一套转录工作区。`/` 与 `/pro` 使用相同的桌面和手机版
界面，不再分别维护“普通 UI”和“Pro UI”：

- `/pro` 始终要求登录，并启用当前账号的云端会话与同步。
- `/` 是否允许访客本地模式由服务器的匿名访问配置决定；不允许时也会进入登录页。
- 管理后台仍是独立入口 `/pro/admin`，只对有权限的账号显示。

## 界面速览

桌面端左侧是导航、最近会话和账号入口；中间是当前会话标题、状态、原文/
译文阅读区与录音控制。移动端使用同一套功能，把历史、设置、AI 助手、洞察
和导出收进适合触控的抽屉，不是另一个精简版前端。

转录区可以切换：

- **双语**：同一片段显示原文与译文；
- **原文**：只显示识别文本；
- **译文**：只显示已完成翻译。

“会话洞察”包含时长、片段数、说话人数、待同步数、翻译完成度，以及面向
英文的本地词/双词组统计。词汇表支持搜索、停用词过滤、单词掌握/学习状态、
CSV 导出和跳转 AI 释义。具备相应服务端权限时，还可以查看 API 请求、Tokens、
功能分类和最近调用使用的模型/延迟。

## 开始、暂停、停止与继续

1. 点击中央麦克风按钮，按设置中的音源授权麦克风和/或屏幕分享（系统音频），
   开始一个**新会话**。
2. 最终转录和译文会增量写入 IndexedDB；如果启用了本地录音，音频也会按块
   追加保存。
3. 录音中可以暂停并恢复；网络短暂中断时状态会显示重连。
4. 点击停止后，DreamTrans 会收尾当前写入，但不会重组整段历史音频。
5. 从历史中加载已有会话后，点击录音按钮旁的 **Continue**，可沿用同一个
   `session_id`、时间轴和音频块序号继续录制。直接点击中央麦克风则开始另一
   个新会话。

Continue 仅在已加载会话且录音处于空闲状态时显示；即使会话还没有最终转录，
也可以继续。它不同于录音过程中的“暂停后恢复”。

新会话的本地录音由独立 Worker 增量编码为 MP3 帧，因此多次 Continue 后仍能
顺序导出同一个可播放文件。旧版本留下的 WebM/M4A 容器不能与新 MP3 帧安全
拼接；对这类已有录音，请先下载旧音频，或者关闭“保存本地录音”后只继续文本
转录，界面不会静默生成损坏的混合格式文件。

## 设置

设置保存在当前浏览器，分为以下几类：

- **语言与翻译**：原始语言、目标语言、是否启用 Speechmatics 实时翻译。
  这些选项在会话进行中锁定，下一次开始/继续会话时应用。
- **阅读体验**：自动跟随最新内容、降低视觉效果。降低效果适合较慢的手机或
  低性能设备。
- **音频输入**：选择实时转录监听的音源。
  - **麦克风**（默认）：只采集本机麦克风。
  - **系统 / 标签页音频**：通过浏览器屏幕分享捕获电脑或标签页里正在播放的声音
    （例如会议远端、视频、系统播报）。开始录音时会弹出分享对话框，需勾选
    「分享音频 / Share audio」。
  - **麦克风 + 系统音频**：把本机说话声与电脑声音混合后送转录。
  桌面端 Chrome / Edge 支持最好；Safari 与多数移动浏览器可能无法捕获系统声音。
  该选项在会话进行中锁定，下一次开始/继续会话时应用。
- **本地数据**：是否保存本地录音。关闭后仍可保存和导出文本，但无法下载
  未保留的音频；该选项在会话进行中锁定。
- **AI 与费用控制**：自动 AI 入库、回答提示词，以及管理员允许时可用的
  自带 API Key/Base/Model。

“自动 AI 入库”默认**关闭**。关闭时，最终转录不会被后台自动发送去做摘要
和向量化，因此仅仅录音不会产生这部分 AI 费用。向 AI 助手提问仍是一次
明确的模型请求；它会附带当前会话的近期文本。开启自动入库后，最终片段会
排队发送到 `/api/rag/ingest`，可能产生摘要和 Embeddings 用量。

自带 API Key 只有在管理员打开 `ALLOW_USER_API_KEY` 后才会显示。Key 只保存
在当前标签页的 `sessionStorage`/内存中，关闭标签页或退出登录即清除；Base、
Model 和提示词等非密钥偏好可保存在当前浏览器的 `localStorage`。自带配置只
随主动 AI 请求发送；前端不会读取或显示服务器保存的 Key。

## 历史、本地存储与账号隔离

日常历史列表只读取小型会话元数据，不会为了显示每一行而读取所有音频 Blob
或整份转录。打开一个会话时，文本按页读取；实时列表只渲染可见区域，以降低
长会话的 DOM 和内存压力。

旧版 IndexedDB 会话不会在后台静默全量扫描。界面显示“发现旧版会话”后，
只有点击“迁移旧版历史”才会读取和转换旧数据；录音期间不能执行迁移。

会话仓库中的元数据、转录、录音与云端 outbox 按身份隔离：

- 访客历史属于匿名空间；
- 登录后只列出当前用户拥有的本地缓存/云端会话；
- 切换账号会清空当前工作区视图，并切换到新账号的缓存和待同步队列；
- 本地录音不会随云端转录同步上传。

## 云端与离线同步

登录用户创建的云端会话同时保留浏览器缓存。每个最终转录在上传前先写入
持久化、按账号隔离的本地 outbox；网络失败或刷新页面不会立刻丢掉这批待
同步文本，当前账号恢复后会继续重试。云端快照与本地记录合并时，较新的本地
片段不会被较短的远端快照截断。

打开云端会话时，DreamTrans 会优先拉取并合并远端快照；如果云端暂时不可用，
但当前账号在这台设备上已有该会话缓存，界面会提示降级并直接打开本机文本，
因此已缓存会话可以离线阅读。第一次打开一台设备上从未缓存过的云端会话仍然
需要网络。

离线读取不等于离线转录：Continue 仍需要连接 Speechmatics/后端。本地录音
也只属于这台设备，不是云端音频备份。

## 下载完整音频与文本

“下载与导出”可以生成原文、译文或双语 `.txt`，以及启用本地录音时的完整
音频。完整音频仍然可以下载，并且录音保存过程中不会反复拼接整个文件：

- 支持 File System Access API 的 Chromium 浏览器会先让你选择目标文件，
  再把 IndexedDB MP3 帧块顺序写入磁盘，适合很长的录音；
- 其他浏览器会在你明确点击“下载完整音频”时才把音频块组合成一个 Blob。
  这不会影响日常保存，但超长录音的这一次下载可能需要较多内存。
- 如果取消文件选择，下载会取消，不会创建残缺文件。

新录音统一导出为 `.mp3`。显式迁移的旧版会话仍保留原来的 `.webm`、`.m4a`
或其他容器格式，下载时不会在后台偷偷转码整段历史录音。

## AI 助手与摘要

AI 助手包含“对话”“一键整理”和“资料”三个标签。一键整理可生成摘要、笔记和行动项，点击后按 AI 模型用量计费。对话支持 Markdown，响应下方在
服务端返回数据时显示模型、Tokens 和延迟。每个会话最多保留最近 50 条聊天
记录在当前浏览器，可在面板内清空。

“一键整理”由你点击生成，内容存到当前会话；“资料”用于管理本会话的资料和索引。需要补建索引时会先展示用量预估。详细流程和接口见 [RAG.md](./RAG.md)。

## 长会话使用建议

- 长时间录音建议保持“保存本地录音”开启，并使用 Chromium 的流式文件下载。
- 手机浏览器可能被系统休眠或回收页面；保持页面前台并避免省电策略终止麦克风。
- “待同步”不为零时不要主动清理站点数据；队列会在网络和账号恢复后重试。
- IndexedDB 仍受浏览器磁盘配额限制，重要会话应及时导出文本和音频。

部署和权限配置见
[ENVIRONMENT_VARIABLES.md](./ENVIRONMENT_VARIABLES.md) 与
[DOCKER_DYNAMIC_CONFIG.md](./DOCKER_DYNAMIC_CONFIG.md)。

## Pro 批量转录

在工作区侧栏或手机菜单选择“批量转录”。选择音频后先查看预估费用，再提交。最多同时准备 10 个文件、合计 100 MB，支持浏览器可解码的音频，单文件约 54 分钟。上传完成后，服务器负责查询、保存到历史和结算，关闭浏览器不影响后台处理；换设备登录后也能在此入口找到最近 100 个任务。

上传响应不确定时不要重新付费上传。任务会自动核对，也可点击“重试查询 / 保存”；长期无法确定时提供任务 ID 联系管理员。移除列表项只隐藏当前设备的任务展示，不删除云端历史。
