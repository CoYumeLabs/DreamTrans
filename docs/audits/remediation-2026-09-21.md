## 增量结构调整

- 工作区主 hook 从约 3,935 行缩为组合入口；录音、持久化、历史列表/操作和同步分别管理，运行时持有稳定状态。开始与续录共用传输配置、音频捕获和失败清理。识别模型、定稿参数、音频格式和欠费暂停顺序保持不变。
- Go 入口拆为应用生命周期、路由、身份与 HTTP 辅助代码；不再用包级变量持有主站服务依赖。
- 运维主生命周期状态使用带版本检查的结构体；发布协议字段通过类型校验，未知扩展字段保留，避免旧工具回写时抹去新字段。Docker/控制接口 JSON 和可扩展配置仍保留映射形式；没有更换磁盘格式版本。
- RAG、翻译 WebSocket、Speechmatics 代理按上下文、鉴权、计费、重放、排序和音频水位等职责拆分，继续使用原有公共处理入口。
