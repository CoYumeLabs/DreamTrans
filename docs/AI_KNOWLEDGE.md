# AI 与资料知识库

主持工作台的「资料与 AI」可上传讲义、配置提示词与检索数量。每个现场问题支持通用建议和基于资料的回答；草稿、来源与资料只有主持人可见。默认手动点击「生成 AI 建议」，也可开启新问题自动生成。AI 建议不会自动上屏。

## 连接 Yufolo

先更新 Yufolo，再更新 YuAction。无需给 YuAction 再配置 AI 密钥；调用 Yufolo 当前账号的项目、文档提取、检索、模型与额度。

上传第一份资料会创建一个对应活动的 Yufolo 项目，也可在设置里选择已有知识库并保存。上传后等待「可检索」；可先使用现有检索能力，语义索引通过「建立语义索引」显示预计 DP 后确认。删除资料会同时从该 Yufolo 知识库删除，关联其他活动的同一项目也受影响。

通用回答不附带其他会话历史；资料回答传入已关联项目和当前活动的转录会话。更新 Yufolo 新增的 `stateless` 模式只影响明确使用该参数的请求，普通聊天仍保留历史。生成回答和观众译文消耗主持人 Yufolo 额度，观众无需账号。后端重启或主持人退出后，需重新登录并打开工作台才能生成新内容；已保存内容保留。

## 独立安装

没有配置 `YUFOLO_URL` 时，可在 YuAction 安装目录 `.env` 设置：

```dotenv
OPENAI_API_KEY=你的密钥
OPENAI_API_BASE=https://api.openai.com/v1
OPENAI_MODEL=你的服务商支持的聊天模型
OPENAI_EMBEDDING_MODEL=text-embedding-3-small
```

也支持完整 `OPENAI_API_URL`（聊天地址）、`OPENAI_EMBEDDING_API_URL` 和 `OPENAI_EMBEDDING_API_KEY`。向量接口默认复用聊天接口的 API base 和密钥。保留 AnyQA 的旧 `OPENAI_API_KEYs` 拼写兼容；聊天模型必须显式配置。修改后执行安装更新命令重建服务。

独立模式上传后自动提取并生成向量，会调用配置的向量服务。支持 UTF-8 TXT／Markdown／CSV／JSON、HTML、文本 PDF、DOCX、XLSX；单文件 10 MB、18 万字，每活动最多 20 份。扫描 PDF 请使用 Yufolo 的提取功能；旧 XLS 请先另存为 XLSX。

向量模型或接口变更后资料显示需要重新索引；失败与重启中断均提供重试。删除资料或切换知识库使已有资料回答失效，后台旧任务不能覆盖失效标记或复活已删除问题。

## 保存和边界

资料、配置和草稿保存到独立的 `room_private_items` 表，更新自动迁移，并由现有数据库备份覆盖。原始资料不进入参与者房间快照或 SSE。

当前为单后端进程运行，最多四个并行 AI 任务。长课堂、真实供应商的质量与费用需要现场验证；自动测试使用模拟供应商，不消费真实额度。本版没有自动迁移旧 AnyQA 的 MySQL 数据，也未完成旧版多语言界面迁移。
