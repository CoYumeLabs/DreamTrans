# 开发路线

## 0.1 · 可运行的房间原型（本次实现）

- [x] 独立 YuAction 工程、Go / React / TypeScript / PostgreSQL
- [x] 创建课堂 / 演讲，房间码、二维码、分享链接
- [x] 主持人、参与者和大屏视图
- [x] 提问、引用字幕、上屏、解答状态、结束活动
- [x] SSE 广播、重连快照、并发写入保护
- [x] 房间主持权限与服务端字幕接收接口
- [x] 演示字幕（无真实音频采集）

## 0.2 · 真实的“一台主机，全场同步”

- [ ] 与 Yufolo 确认共享房间 API 及两侧授权方式
- [ ] 主持人从 YuAction 创建 / 关联 Yufolo 房间
- [ ] 单路音频采集、暂停、恢复、结束与失败状态
- [ ] 房间绑定的集成凭证、服务端重试与消息确认
- [ ] 最终 / 临时字幕、说话人、时间戳、顺序游标
- [ ] 同语言共享译文，参与者语言切换
- [ ] 明确计费归属及余额不足时的全房间状态

验收：一位主持人、两位听众和一块大屏，真实转录同步；上游仅有一条识别连接。中断再连接不重复扣费、不重复建房、不丢最终字幕。

## 0.3 · 可邀请真实用户试用

- [ ] 账户接入、活动成员与角色、主持人密钥恢复 / 撤销
- [ ] 参与者级别限流、问题审核、删除与举报
- [ ] 字幕 / 问题独立持久化、分页和增量事件
- [ ] PostgreSQL 版本化迁移、备份与数据保留策略
- [ ] 实际校园网络条件、移动端、容量和长会话测试
- [ ] 基于公开数据的“没跟上”反馈与问题聚合

## 之后

按真实试用反馈决定：资料知识库、AI 回答参考、理解检查、课后公开问答归档、保存到个人 Yufolo 学习空间。不要在共享房间链路尚未稳定之前扩展大量独立模块。
