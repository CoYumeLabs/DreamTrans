# 开发路线

## 0.1 · 可运行的房间原型（本次实现）

- [x] 独立 YuAction 工程、Go / React / TypeScript / PostgreSQL
- [x] 创建课堂 / 演讲，房间码、二维码、分享链接
- [x] 主持人、参与者和大屏视图
- [x] 提问、引用字幕、上屏、解答状态、结束活动
- [x] SSE 广播、重连快照、并发写入保护
- [x] 房间主持权限与服务端字幕接收接口
- [x] 演示字幕（无真实音频采集）

## 0.2 · 真实的“一台主机，全场同步”

- [x] 复用 Yufolo 现有账号与转录接口，服务端保管凭证
- [x] 主持人从 YuAction 幂等创建关联的 Yufolo 会话
- [x] 单路音频采集、暂停、手动继续、结束与失败状态
- [ ] 房间绑定的集成凭证、服务端重试与消息确认
- [ ] 最终 / 临时字幕、说话人、时间戳、顺序游标
- [x] 主持人选择一种共享译文，观众选择原文／双语显示
- [ ] 不同观众分别选择翻译目标语言
- [x] 转录归属主持人 Yufolo 账号，失败状态同步到房间

已验证：模拟上游的浏览器采音和字幕共享；隔离的真实 DreamTrans 后端登录、幂等会话关联和字幕归档接口；同房间并发开麦限制。真实付费语音识别效果、长课堂和多语言边界仍需现场验证。

## 0.3 · 可邀请真实用户试用

- [x] Yufolo 账号接入及跨浏览器恢复主持权限
- [ ] 活动成员、多主持人角色与旧密钥撤销
- [ ] 参与者级别限流、问题审核、删除与举报
- [ ] 字幕 / 问题独立持久化、分页和增量事件
- [x] PostgreSQL 版本化迁移与更新前备份
- [ ] 定期备份与数据保留策略
- [ ] 实际校园网络条件、移动端、容量和长会话测试
- [ ] 基于公开数据的“没跟上”反馈与问题聚合

## 之后

按真实试用反馈决定：资料知识库、AI 回答参考、理解检查、课后公开问答归档、保存到个人 Yufolo 学习空间。不要在共享房间链路尚未稳定之前扩展大量独立模块。
